## ✨ 핵심 기능 요약

1. **대한민국 모든 행사·기념일·절기·잡절 100% 총망라 (2020년~2032년+ 약 2,580여 건 기본 내장)**
   - **🔴 법정공휴일 & 대체공휴일 완벽 계산**: 설·추석 연휴, 삼일절, 어린이날, 부처님오신날, 현충일, 광복절, 개천절, 한글날, 성탄절 및 최신 「관공서의 공휴일에 관한 규정」 대체공휴일·전국 선거일까지 100% 정확히 산출합니다.
   - **🇰🇷 5대 국경일 & 태극기 게양법 안내**: 3·1절, 제헌절, 광복절, 개천절, 한글날(경축일 게양법) 및 현충일·순국선열의날(조기 게양법) 상세 해설을 수록했습니다.
   - **🏛️ 75종 국가 법정기념일 전수 수록**: 과학의 날, 정보통신의 날, 어버이날, 스승의 날, 국군의 날, 경찰의 날, 소방의 날, 농업인의 날, 김치의 날, 우주항공의 날 등 고정 기념일과 '몇째 주 무슨 요일' 가변 기념일(성년의 날, 청년의 날, 바다/문화/금융/상공/서해수호의 날 등)을 모두 포함합니다.
   - **🌿 한국천문연구원 역서 규격 24절기 & 🌕 잡절(삼복 등)**: 태양 황경(15° 간격) 천문 계산으로 산출한 24절기(입춘~동지, KST 절입 시각 포함)와 육십갑자 일진(경일·무일·미일)으로 정밀 산출한 **초복·중복·말복**, 한식, 단오, 정월대보름, 삼짇날, 유두, 칠석, 백중, 중양절, 납일, 섣달그믐을 제공합니다.
   - **🏮 음력 초하루(1일)·보름(15일) & ⭐ 나만의 양력/음력 기념일 추가**: 음력 생신이나 제사를 등록하면 매년 양력 날짜로 자동 변환되어 달력과 공유 파일에 함께 들어갑니다.
2. **내가 필요할 때 언제든 캘린더 파일(`.ics`) 생성 & 공유 스튜디오**
   - **6종 기본 프리셋 `.ics` 파일** 상시 제공 (`전체 통합본`, `빨간날(공휴일) 전용`, `공휴일+절기+삼복 실속본`, `24절기+잡절 전용`, `법정기념일 전용`, `음력 초하루·보름 전용`)
   - **맞춤 공유 캘린더 빌더**: 원하는 분류, 연도 범위, 음력 병기 여부, 미리 알림(하루 전/당일 오전 9시)을 골라 **`output/shared/` 보관함에 공유 전용 `.ics` 파일 생성**, **고유 공유 링크(`/share/<id>.ics`) 발급**, **스마트폰 카메라 스캔용 QR코드 즉시 생성**, **엑셀(CSV) 내보내기**를 지원합니다.

## 🐳 시놀로지 NAS 도커(Container Manager / Portainer) 설치 방법

```yaml
services:
  korea-calendar:
    image: kimmingil/korea_calendar:latest
    container_name: korea_calendar
    restart: unless-stopped
    init: true
    user: "1026:100"
    ports:
      - "38503:8500"   # 시놀로지 호스트 38503 포트 -> 컨테이너 내부 8500 포트
    environment:
      - TZ=Asia/Seoul
      - KOREA_CAL_HOST=0.0.0.0
      - KOREA_CAL_PORT=8500
      - DATA_GO_KR_SERVICE_KEY=   # 선택사항 (웹 대시보드에서도 실시간 입력/저장 가능)
    volumes:
      - ./output:/app/output      # 6종 기본 .ics 및 공유 보관함(output/shared) 폴더
      - ./data:/app/data          # API 설정, 커스텀 기념일 및 캐시 폴더
      - ./logs:/app/logs          # 로그 폴더
```
